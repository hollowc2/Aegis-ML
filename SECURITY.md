# Security policy

Aegis-ML is a portfolio and research project, not a guarantee that arbitrary
LLM traffic is safe. Review the documented trust boundaries and limitations in
[docs/THREAT_MODEL.md](docs/THREAT_MODEL.md) before deployment.

## Reporting a vulnerability

Please do not publish sensitive exploit details in a regular GitHub issue.
Use GitHub's **Report a vulnerability** link in the repository Security tab to
open a private advisory. If private reporting is not enabled, contact the
repository owner through the public profile and disclose only enough
information to establish a private channel.

Include affected versions, reproduction steps, impact, and any suggested
mitigation. Please allow reasonable time for investigation before public
disclosure.
